# Медицинская аналитика — Северо-Западный ФО

Веб-приложение для просмотра аналитики продаж (БАД) по районам на локальной
карте и в разрезе данных. Данные берутся из Excel-выгрузки.

## Вкладки

- **Карта** — локальная SVG-карта (без внешних тайлов): районы СПб и
  Ленинградской области, клик по району выделяет его и показывает статистику,
  цвет заливки = объём продаж выбранного периода. Маркеры аптек и поликлиник.
- **Данные** — аналитика по выгрузке: KPI (сумма, штуки, бонусы, участники),
  фильтры (субъект, канал, сеть, продукт), графики (продукты, сети, субъекты,
  районы СПб, недели), таблица участников.

## Стек

React + TypeScript + Vite, SCSS, данные — JSON (подготовлен из Excel через
pandas). Ни одного внешнего сетевого запроса — работает офлайн.

## Данные

Источник: Excel-файл с листом `Data` (дата, ИНН/название участника, субъект РФ,
район города, канал, БАД, сеть, количество, сумма продаж, бонус).
Препроцессинг в `public/data/sales.json` (компактные записи).

Чтобы обновить данные: замените содержимое `public/data/sales.json` новой
выгрузкой (поля: d, m, sub, ct, dst, ch, p, n, pt, q, s, b).

- `public/data/districts.geojson` — полигоны районов (name, region, population, areaKm2, scale)
- `public/data/objects.json` — аптеки и поликлиники (name, type, district, lon, lat)
- `public/data/sales.json` — строки продаж

## Запуск

```bash
npm install
npm run dev      # разработка
npm run build    # сборка в dist/
```

## Структура

- `src/pages/Home.tsx` — главный экран, вкладки, состояние фильтров.
- `src/components/MapView.tsx` — локальная SVG-карта районов и маркеров.
- `src/components/DataTab.tsx` — вкладка «Данные»: KPI, графики, таблица.
- `src/data/sales.ts` — загрузка и агрегация продаж.
